# Leon Lin's Cook workflow, with a running example

A step-by-step explanation of how Leon Lin prompts an agent to build demos that hold up next to their references, and how his `/cook` skill runs the same steps as a loop. One invented example project (a harbor town at dusk in three.js) runs through every step.

**Live page:** https://az9713.github.io/lin-cook-skill-example/

## Sources

- Leon Lin, "How I prompt AI to build good looking demos", X article, 31 Oct 2026: https://x.com/LexnLin/status/2116662591363690999
- Leon Lin, `cook` skill: https://github.com/Leonxlnx/cook
- AI Labs, YouTube video on Leon Lin's process and the Cook skill: https://www.youtube.com/watch?v=-bv2xKQzZio

The running example on the page is invented to show the mechanics. Its times and scores are not measurements. This page is an independent study, not made by or endorsed by Leon Lin or AI Labs.
